# Estrutura de Dados

Repositório de listas e tarefas da disciplina de Estrutura de Dados, com enunciados em PDF e implementações em C++.

## Organização

| Diretório | Conteúdo |
|---|---|
| [`listas_2023`](./listas_2023/) | Enunciados das listas e implementações disponíveis para as listas 0, 1 e 2. |
| [`listas_2024`](./listas_2024/) | Exercícios sobre `switch` e ponteiros, incluindo listas e pilhas aplicadas à Torre de Hanói. |
| [`tarefa_01`](./tarefa_01/) | Programas para classificar IMC e verificar ano bissexto. |
| [`tarefa_02`](./tarefa_02/) | Operações em lista duplamente encadeada: inserção, busca e remoção de nós. |
| [`testes`](./testes/) | Enunciados de provas e exercícios em C++. |

## Como compilar

Compile cada arquivo `.cpp` separadamente, pois os exercícios têm seus próprios programas. Exemplo para a segunda tarefa:

```bash
g++ -std=c++11 tarefa_02/main.cpp -o tarefa_02
./tarefa_02
```
